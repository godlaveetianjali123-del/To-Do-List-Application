# 📝 To-Do List App

A modern and responsive **To-Do List Application** built using **HTML, CSS, and JavaScript**. This project allows users to efficiently manage daily tasks with full CRUD functionality, task filtering, and Local Storage support so tasks remain available even after refreshing or reopening the browser.

---

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as completed
- 🔍 Filter tasks (All, Active, Completed)
- 💾 Local Storage support (data persists after page reload)
- ⌨️ Add tasks using the Enter key
- 📱 Responsive and modern user interface
- ⚡ Dynamic DOM manipulation using Vanilla JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Install the **Live Server** extension (if not already installed).
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. Start managing your tasks.
